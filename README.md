# 教案小助手 · Lesson Pack

> 面向中小学老师的一节课**成套备课**生成器：输入「学科 + 年级 + 课题 + 课时长」，一次产出 **教学设计（教案）+ 教学课件 PPT + 学习任务单（学案）+ 分层练习题（含答案）+ 课后作业**，全环节时间严格等于课时长。

## 它解决什么问题

老师备一节课通常要同时搞**五样东西**：教案、课件、学案、练习卷、作业。多数 AI 工具只给一段"教案参考"，剩下四样还得自己拼；且常**不看课时长**，一节课 40 分钟，课件却排了能讲一小时的量。

教案小助手把这件事收敛成一句话：**给你一节课的"内容 + 时长"，还你一套能直接拿去上的完整配套。**

- 🇨🇳 **中国课标/人教版适配** —— 流程按新课标「导入 → 新授 → 巩固 → 小结 → 作业」规范走，可喂教材原文，不让 AI 空想跑偏。
- ⏱️ **时长驱动** —— 课时长是核心参数，不是装饰。输入 40 / 45 / 90 分钟 → 反推每个环节精确分钟，**分钟总量严格对齐**，杜绝"5 分钟能讲完却排 10 页课件"。
- 🔗 **单源派生、全套一致** —— 先完整设计好一堂课（一份内容 JSON），再从同一份底层结构派生教案 / PPT / 学案 / 练习 / 作业。**PPT 页数对教案环节、练习目标对教学目标**，全程对得上，不是各写各的。
- 🪶 **轻量、纯本地** —— 不登录第三方平台、不联网抓素材、不需要一堆账号。产物全落在你自己的目录，未成年人信息零接触。

## 产物一览

同一份内容源，两种交付形态（各一条命令）：

| | **档 A · HTML 教学包** | **档 B · Office 文件包** |
|---|---|---|
| 产出 | 一份自包含 `.html`（教学设计/学案/练习/作业逐页"纸张"） | 5 个真实文件：`教学设计.docx` `学习任务单.docx` `课堂分层练习.docx` `课后作业.docx` `教学课件.pptx` |
| 用途 | 浏览器直接看 / 转 PDF / 打印；**先看效果、快速验证内容** | **可编辑、可打印、可上交**给学校 |
| 依赖 | 纯 Python 标准库，零第三方 | `python-docx`（必须）+ `python-pptx`（可选） |

> 建议流程：先出**档 A** 看效果、确认内容，再出**档 B** 文件包交付。两档内容完全一致，因为它们吃同一份源。

视觉上刻意做成"复印出来的一叠 A4 教案与卷子"，而不是花哨的 AI 展示页：米灰底 + 暖白纸面 + 楷/宋衬线 + 主体黑墨，仅用"红笔批注"标时间/重难点/易错、少量蓝标栏目——像老师红笔改过的痕迹，可直接打印。主题（档 B）默认数学深蓝，可换学科预设或自定义主色。

## 快速开始

### 方式 A：作为 WorkBuddy Agent Skill 使用（推荐给老师）

> ⚠️ 本仓库目录同时是「开源 git 项目」+「Skill 包」两种形态。**不要直接 `cp -r` 整个目录**——会把 `.git`（超深嵌套）一并带进去，Skill 解析器会报「目录层级超限，仅支持两级目录结构」。请用发布脚本生成合规的干净副本后再装：

```bash
# 1) 生成干净的两级 Skill 包（产出 dist/lesson-pack/ 与 dist/lesson-pack.zip）
bash scripts/make_skill_release.sh

# 2) 装到用户级 Skills 目录（macOS / Linux）
rsync -a dist/lesson-pack/ ~/.workbuddy/skills/lesson-pack/
```

也可以在 WorkBuddy 里直接导入 `dist/lesson-pack.zip`。

装好后，在 AI 助手（如 WorkBuddy）里直接说：

```
帮我备一节数学课，八年级上一次函数，45 分钟
这节课上《咏雪》，1 课时，40 分钟，给我教案和课件
临时代课，明天讲化学《金属的化学性质》，我没教过，帮我备
```

Skill 会按 `SKILL.md` 里的流程走：补必填字段 → 设计单源 → 落成内容 JSON → 派生出档 A / 档 B 全套到你的工作区。

### 方式 B：纯 Python 命令行（独立于任何 AI 助手）

不依赖 AI 助手也能用脚本，只要内容 JSON 就绪（结构见下文 / 模板里的示例）。

```bash
# 档 A：生成 HTML 教学包
python3 scripts/lesson_pack_html.py \
  --data "我的教案.json" \
  --out 教学包.html

# 档 B：生成 Office 五件套（--theme 可换学科或自定义主色）
python3 scripts/lesson_pack_gen.py \
  --out "./教学包_真实文件" \
  --data "我的教案.json" \
  --theme 语文
```

不传 `--data` 时，`lesson_pack_gen.py` 会用内置的七年级数学《一元一次方程》样例演示（仅便于试跑，正式使用请务必 `--data`）。

### 环境要求

| 工具 | 档 A | 档 B |
|---|---|---|
| Python | 3.8+ | 3.8+ |
| 第三方包 | 无 | `python-docx`（必须） |

```bash
pip install python-docx
# 可选：要生成 PPT 则再装
pip install python-pptx
```

> `python-pptx` 缺失时 `lesson_pack_gen.py` 会优雅降级：正常产出 4 个 `.docx`，仅跳过 `.pptx` 并打印提示。

## 内容源 JSON（核心：一份源，全套派生）

所有配套都从**一份内容 JSON** 派生。推荐结构（四个顶层键）：

```jsonc
{
  "lesson": {                      // 一节课的全部设计
    "学科": "语文", "年级": "七年级", "课题": "咏雪", "课时": "40",
    "教学目标": [["知识与技能", ["…", "…"]], ["过程与方法", ["…"]], ["情感态度", ["…"]]],
    "重难点": ["重点：…", "难点：…，突破：…"],
    "时间总表": [["课堂导入", 4], ["新知探究", 18], …],   // 求和必须 == 课时
    "环节": [                       // 每环节含 教师活动/学生活动/设计意图 三栏
      {"名": "一、课堂导入", "分": "4", "rows": [["教师活动", "…"], …]}
    ],
    "板书": {"title": "咏雪", "left": […], "mid": […], "right": […]}
  },
  "worksheet_tasks": [["任务一 · 朗读正音", "1", "给加点字注音：…"]],  // 学案题
  "exercises": [["★ 全班必做", [["1", "题干…", "答案…"], …]]],       // 分层练习（基础）
  "homework": {"A 组 · 基础必做": [["1", "题干…", "答案…"]],          // 课后作业（分 A/B/C 组）
               "B 组 · 提升选做": […], "C 组 · 拓展挑战": […]}
}
```

- 详细字段说明见 [`templates/lesson-content.schema.md`](templates/lesson-content.schema.md)。
- 可直接抄的完整可跑样例：**语文《咏雪》40 分钟** [`templates/示例_语文_七年级_咏雪_40分钟.json`](templates/示例_语文_七年级_咏雪_40分钟.json)（语文），以及脚本内置的**数学《一元一次方程》45 分钟**样例。

> **当你在用 AI 助手（WorkBuddy）时，这份 JSON 不必手写**——把备课需求说清楚，AI 会替你设计单源、写成 JSON 并派生全套。JSON 主要面向：命令行方式、想精细手工控制内容、或想复用/二次编辑一版教案的老师。

> ⚠ **缺失键不会用内置样例回填**：早期版本缺哪个键就拿内置《一元一次方程》补上，会产出「语文《咏雪》的作业里全是方程题」这种串味事故。现在改为**缺哪个顶层键就跳过对应产物并打印原因**（例如只给 `lesson` 就只出「教学设计 + 教学课件」）。宁缺勿错。

## 质量怎么保证

1. **时间账硬校验**：`时间总表` 求和 **和** `各环节[].分` 求和，两条都必须精确等于 `课时`。不等则打印 ⚠ 明细（默认只告警继续生成）；加 `--strict-time` 可让不平直接终止、退出码非 0、不产出文件。档 A / 档 B 用同一套校验规则。
2. **缺字段不静默**：缺必填字段时档 A 直接报错退出；档 B 跳过该产物并在结尾汇总，**退出码非 0**——不会让你拿到一个"看起来生成成功"的残缺包。
3. **quality-checklist.md**：交付前逐条核对——目标用可测动作动词、环节含"当堂检验"、练习含基础+提升分层并标明给谁、配套（PPT大纲=教案环节、练习目标=教学目标、题号无跳号）、内容量与时长匹配、**不采集学生真实个人信息、学情只用描述性分层**。任一不过即返工。

### 已知取舍（欢迎 PR）

- 当前 `教学课件.pptx` 是**数据驱动通用课件**（封面/目标/重难点/各环节页/小结/作业，页数随环节动态，任意学科可用）。它比早期"数学专属 16 页"精装版更通用，但也更朴素——丢了天平示意、四步流程、易错警示、例题板书这类**理科强视觉页**。若你希望数学/物理有学科专属高颜值课件，可扩展 `lesson_pack_gen.py` 的 `make_ppt`，按 `lesson.学科` 走学科模板分支（数据驱动 + 学科装饰层）。
- **档 A 目前不含课件**：HTML 教学包只有「教学设计 / 学案 / 分层练习 / 作业」四张纸，课件要走档 B 的 `.pptx`。想让档 A 也能预览课件，可在 `lesson_pack_html.py` 里加一张"课件大纲"纸（把 `lesson.环节` 按 PPT 页序平铺即可，数据现成）。
- **主题系统仅档 B 有**：`--theme` 只作用于 docx/pptx。档 A 固定"红笔批注 + 蓝栏目"的纸质教案配色，这是刻意保持的印刷质感，非缺陷。

## 二次开发 / 贡献

- 结构很薄：内容 JSON 是**唯一事实源**，两个脚本各自单向地把 JSON 渲染成 HTML / Office。想改某张纸的版式，只动对应脚本的渲染函数即可，不影响另一档。
- 派生顺序要先 `esc()` 再插 HTML 元素（填空线替换），否则会漏出原始标签——详见 `SKILL.md` 易错点与 `scripts/lesson_pack_html.py` 的 `body_multi`。
- 欢迎提 issue / PR：更多学科 PPT 模板、方言适配、其它课型配比、英文/多语支持。
