# lesson-content 单源 JSON schema（档 A / 档 B 通用数据源）

> 这是**机器可读**的单源内容结构，供档 B 脚本 `lesson_pack_gen.py --data <此json>` 直接消费，
> 也是档 A HTML 生成脚本的同源输入。写 JSON 前先用 `lesson-design-template.md` 把课"设计"好，
> 再把结果**按本 schema 落成 JSON**。设计(md)管质量，schema(json)管数据一致性。
>
> 完整可运行示例：同目录 `示例_语文_七年级_咏雪_40分钟.json`（直接 `--data` 它可出全套文件）。

## 顶层结构

一个 JSON 对象，含 **4 个顶层键**（对应脚本里 4 个数据结构）：

> ⚠ **缺失键的处理（2026-09-02 修正）**：早期版本"缺哪个键就用内置数学样例回填"，会产出
> 《咏雪》的学案里全是一元一次方程这种串味事故且无任何提示。现在改为：
> **缺哪个顶层键，就跳过对应产物并明确打印原因，绝不回填内置样例。**
> 只给 `lesson` 也能跑，只会得到「教学设计 + 教学课件」两份，不会给你错误的题目。
> 内置数学样例仅在「不传 `--data`」时作为演示生效。

```jsonc
{
  "lesson":          { /* dict：整节课的单源设计，见下"lesson 字段" */ },
  "worksheet_tasks": [ /* 学案(学习任务单)的题，list */ ],
  "exercises":       [ /* 分层练习，list of [组名, [[题号,题面,答案]…]] */ ],
  "homework":        { /* 课后作业，dict：组名 → [[题号,题面,答案]…] */ }
}
```

## lesson 字段（dict，必填）

| JSON 键 | 类型 | 说明 / 示例 | 必填 |
|---|---|---|---|
| `学科` | string | "语文" / "数学" … | ✅ |
| `年级` | string | "七年级" | ✅ |
| `教材` | string | "部编版语文七上" | ✅ |
| `章节` | string | "第二单元" | ✅ |
| `课题` | string | "咏雪" | ✅ |
| `课型` | string | "新授课" | ✅ |
| `课时` | int | 40 | ✅ |
| `课时标签` | string | "第 1 课时" | ✅ |
| `教学目标` | array | `[["知识与技能", ["…","…"]], ["过程与方法",[…]…]]` 每维 [类别, 条目数组] | ✅ |
| `重难点` | array(3) | `["重点…","难点…","难点突破策略…"]` 三元素 | ✅ |
| `学情` | string | 描述性、不实名 | ✅ |
| `时间总表` | array | `[["环节名", 分钟]…]` | ✅ |
| `环节` | array of obj | 见下"环节对象" | ✅ |
| `板书` | object | `{title,concept,left[],mid[],right[]}`（left/mid/right 为字符串数组，每元素一行） | ✅ |
| `作业说明` | string | 作业量说明，如"预计 15 分钟完成"；提供 `homework` 时必填 | ✅ |
| `练习时长` | int | *选填*。课堂练习卷页首标注的建议用时；不给则自动取名称含"练习/巩固/训练/检测"的环节分钟，再兜底 = 课时/3（5–20′）。档A/档B 取同一值 | ⬜ |

### 环节对象（lesson.环节 的每个元素）

```jsonc
{
  "名": "一、课堂导入",
  "分": 4,                          // 本环节分钟(整数)
  "rows": [                          // 每行 [栏名, 内容]
    ["教师活动", "出情境……"],
    ["学生活动", "口答……"],
    ["设计意图", "从生活切入唤起旧知……"],
    ["当堂检验", "抽 2–3 人说出……"]   // 形成性评估
  ]
}
```

## 硬规则（脚本与 quality-checklist 双重校验）

1. **时间账**：`lesson.时间总表` 各分钟相加 **必须精确 = `lesson.课时`**。
2. **环节与时间总表对应**：`lesson.环节[].分` 之和也必须 = `lesson.课时`；PPT 页数由此派生。
3. **一致性**：练习/作业题目标向 `lesson.教学目标`；题号不重复、不跳号。
4. **合规**：`学情`、题干一律用描述性分层（基础薄弱/中等/优秀），**绝不出现真实学生姓名/个人信息**。
5. 换行内容（如题干多行）用 JSON 里的 `\n` 表示即可。

> **脚本校验（档A/档B 同一套规则）**：两条时间账都会核，不等则打印 `⚠ 时间账不平` 明细。
> 默认**只告警不阻断**；想让不平就终止，加 `--strict-time`（此时退出码非 0，不产出文件）。
> 缺必填字段：档A 直接报错退出；档B 跳过该产物并在结尾汇总，退出码非 0。

## worksheet_tasks（学案/学习任务单，list）

每元素三元 `[任务名, 序号, 题面]`：

```jsonc
[
  ["任务一 · 朗读", "1", "正确朗读全文……"],
  ["任务二 · 疏通文意（必做）", "2", "解释加点词：①…②…\n翻译句子：……"],
  ["任务五 · 小结自评", "5", "我今天学会了：____　我还想问：____"]
]
```

## exercises（分层练习，list）

每元素二元 `[组名, 组内题list]`，组内题三元 `[题号, 题面, 答案]`。至少"全班必做/能力提升"两档，可加挑战档：

```jsonc
[
  ["★ 全班必做", [
    ["1", "……", "答案"],
    ["2", "……", "答案"]
  ]],
  ["★ 能力提升（大部分同学做）", [
    ["3", "……", "答案"]
  ]],
  ["★ 思维挑战（学有余力选做）", [
    ["4", "……", "答案"]
  ]]
]
```

## homework（课后作业，object）

键为组名，值为该组三元 `[题号, 题面, 答案]` 数组；键序遍历即输出顺序：

```jsonc
{
  "A 组 · 基础必做": [ ["1","…","答案"], ["2","…","答案"] ],
  "B 组 · 提升选做": [ ["3","…","答案"] ],
  "C 组 · 拓展挑战": [ ["4","…","答案"] ]
}
```

## 怎么跑

```bash
# 档 B：一套 5 个真实 Office 文件（教案/学案/练习/作业 docx + 课件 pptx）
python scripts/lesson_pack_gen.py --out ./教学包 --data ./内容.json --theme 语文
# --theme 可省(默认数学深蓝)，或给学科预设名 / '#hex' 自定义主色

# 档 A：单文件自包含 HTML 教学包（浏览器直接看/转PDF）
python scripts/lesson_pack_html.py --out ./教学包.html --data ./内容.json   # 若已提供该脚本
```
