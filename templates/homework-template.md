# 课后作业 · 模板

> 与练习题的差别：练习题偏"当堂检测用"（可课上做），作业偏"回家独立完成"，通常跨一晚上/几天后回收。
> 仍分层，且量与课时匹配，避免 40 分钟课布置超量作业加重负担。

## 作业自检
- □ 预计总时长 ≤ 20 分钟，与课时匹配
- □ 分 A(必做)/B/C 三档，B、C 明确标注选做
- □ 答案与解析齐全（含 C 组参考思路）
- □ C 组最好留一题预告下节，形成衔接
