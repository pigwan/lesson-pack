> 每次设计一节课，AI 必须先填满这份模板并过质量自检，再派生其他产物。

## 六、教学环节（核心！每个环节给精确分钟，总和=课时长）

> 行数、环节名可增删，按课型选骨架；**分钟数是灵魂，必须写死且加总精确等于课时长**。
> 每环节三栏：教师活动 / 学生活动 / 设计意图。另给【形成性评估】注明该环节如何检验学生达成。

### 环节骨架参考（可按课型选）

**新授课**（默认）：
1. 课堂导入（约总时长 10%）
2. 新知讲授（约 40-45%）
3. 巩固练习/应用（约 25%）
4. 课堂小结（约 8-10%）
5. 作业布置与收尾（约 2%）

**复习课**：知识梳理 → 典型例题讲析 → 高频考点专练 → 易错集中突破 → 总结
**习题课/讲评课**：错因归类 → 典型题重讲 → 变式训练 → 补漏检测
**实验课**：情境与问题 → 实验方案 → 操作观察 → 现象分析 → 得出结论
